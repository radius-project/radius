# Hand-reviewed ARN property decisions for AWS resource types that the naming rules in gen/main.go can't settle: types
# with more than one candidate, and types with only other read-only "*Arn" properties. Each line is
# "<type name> <property or none> # reason". Use none when no property holds the ARN of the resource itself. A wrong ARN
# is worse than none, so pick a property only when the CloudFormation schema or the AWS documentation says it is the
# resource's own ARN.
#
# Regenerate with `go generate ./pkg/aws/arnproperties` after editing.

# Two candidates. The AWS docs describe the second property as a synonym of Arn, so both hold the same value.
AWS::Location::Map Arn # MapArn is documented as a synonym for Arn.
AWS::Location::Tracker Arn # TrackerArn is documented as a synonym for Arn.
AWS::OpenSearchService::Domain Arn # DomainArn holds the same domain ARN; Arn is the current name.
